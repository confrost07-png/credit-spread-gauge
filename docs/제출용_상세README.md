# 레고랜드 사태 전후 신용스프레드와 단기자금시장 분석

**Money Catcher 조 · 데이터 분석 미니 프로젝트 (v7 · 최종 제출본)**

> 2022년 9월 28일 레고랜드(강원중도개발공사) 회생신청 발표 이후, **우량 회사채(AA−)의 신용스프레드는 코로나 충격 때의 2.2배까지 벌어졌고, 단기자금시장(CP − CD)은 더 늦게, 그러나 더 크고 길게 흔들렸습니다.** 공공 데이터를 크롤링·API로 모아 이를 수치로 확인하고, 그 결과로 **스프레드 계기판**(평온·긴장·경색)을 투자·조달 판단의 보조지표로 제안합니다.

| 핵심 수치 | 값 |
|---|---|
| AA− 스프레드 정점 | **167bp** (2022.12), 코로나 정점 76bp의 **2.2배** |
| 사건 전 → 경색기 | 96bp → 149bp (**+53bp, +55%**) |
| 단기 신용 불안 (CP − CD, 일별) | 17bp → 102bp (**+85bp**), 사건 직전 범위 복귀는 2023.05.24 |
| 2023년 하반기 | 78bp, 평소(2019–21 평균 46bp)의 **1.7배**. 완전히 회복되지는 않음 |

## 3. 주제 선정 이유와 분석 질문

**왜 레고랜드 사태인가**

1. **신용 위험이 번지는 과정을 볼 수 있는 사건입니다.** 지자체가 보증한 채무가 흔들리자 우량 기업의 자금 조달까지 막혔습니다.
2. **공공 데이터로 수집 과정을 재현할 수 있습니다.** 국고채·회사채·CD 금리가 공공 웹페이지와 한국은행 공개 API에 있습니다.
3. **금융 실무에 바로 쓰이는 지표입니다.** 신용스프레드는 증권사 WM의 채권 투자 안내와 기업 재무팀의 조달 시점 판단에 쓰입니다.

**분석 질문**

| 질문 | 답이 있는 곳 |
|---|---|
| Q1. 사태 전후 우량 회사채(AA−) 신용스프레드는 얼마나 벌어졌고(평소·코로나 충격과 비교해) 언제 회복되었나? | REPORT 6장 |
| Q2. 시장금리가 내려갈 때 신용스프레드도 함께 줄었나? | REPORT 6장 |
| Q3. 단기자금시장(CD·CP)은 회사채 시장과 비교해 언제, 얼마나, 얼마나 오래 흔들렸나? | REPORT 7장 |
| Q4. 과거(2019–21) 기준으로 스프레드를 평온·긴장·경색으로 나누면 투자·조달 판단의 보조지표로 쓸 수 있나? | REPORT 8장 |

## 4. 주요 결과

| 지표 | 사건 전 | 경색기 | 정점 |
|---|---|---|---|
| 회사채 AA− 스프레드 (월별) | 96bp | 149bp (+53bp, +55%) | 167bp (2022.12) = 코로나 정점(76bp)의 2.2배 |
| 회사채 AA− 금리 (월별) | 4.42% | 5.41% (+99bp, +22%) | 5.49% (2022.11) |
| CP − CD (일별) | 17bp | 102bp (+85bp) | 159bp (2022.12.01) |

1. **신용 프리미엄이 1.5배로 커졌고, 코로나 때의 2.2배였습니다.** AA− 스프레드가 사건 전보다 53bp(55%) 커졌습니다. 회사채 금리 전체는 약 1%p(22%) 올랐습니다. 1,000억 원을 새로 빌린다면 스프레드 확대분만으로 연 약 5.3억 원을 더 내는 셈입니다.
2. **금리가 내려도 스프레드는 벌어졌습니다. (Q2)** 2022년 10→12월 회사채 금리는 14bp 내렸지만 국고채가 61bp 내려 스프레드는 47bp 커졌습니다.
3. **추세가 아니라 급변이었습니다.** 사건 전 AA− 스프레드는 하루 평균 +0.32bp씩 오르고 있었지만 발표 다음 날(9/29) 하루에 +7.1bp가 올랐습니다. 사건 전 일간 변화의 약 9표준편차, 기존 추세로는 약 22영업일이 걸릴 폭입니다.
4. **단기자금시장은 늦게, 그러나 더 크고 길게 흔들렸습니다. (Q3)** CP − CD는 23일(15영업일) 뒤(10/21) 사건 직전 범위를 벗어났지만 확대 폭(+85bp)이 더 컸고, 사건 직전 범위 복귀(5영업일 연속 기준)는 2023년 5월 24일로 AA−(1월 30일)보다 4개월 가까이 늦었습니다. 50조원+α 대책 직후 5영업일에도 CP − CD는 +34bp 더 벌어졌습니다.
5. **스프레드 계기판을 제안합니다. (Q4)** 기준값은 분석 기간 밖인 2019–21년 자료로만 정했습니다(평온 ≤ 평균+2σ = 72.7bp, 경색 > 평균+4σ = 99.5bp). 2022–23년에 적용하면 경색은 2022.09–2023.01, 평온 복귀는 2023.03입니다.
   - 경색 구간에 AA− 회사채를 사서 6개월 보유했다면 국고채보다 평균 +221bp(근사, 5회) 더 벌었고, 평온 구간 매수는 −58bp였습니다.
   - 월평균 판정은 월말에야 확정되므로 판정 다음 달에 산다고 다시 계산해도 경색 +205bp, 평온 −81bp로 방향은 같습니다. σ 배수를 3·4·5로 바꿔도 결론은 같습니다.
   - 다만 일별 계기판은 발표 전날(2022-09-27) 이미 경색에 들어갔습니다. 계기판은 스프레드 수준을 판정할 뿐 원인(레고랜드 여부)을 구분하지 못합니다.
6. **완전히 회복되지는 않았습니다. (Q1)** 2023년 하반기 스프레드 평균(78bp)은 2019–21년 평균(46bp)의 1.7배입니다.

### 금융·비즈니스 인사이트

| 관점 | 인사이트 |
|---|---|
| 기업 재무 | 우량 등급(AA−)에서도 코로나 때의 2.2배 충격이 났습니다. 확대분(53bp)을 신규·차환 조달 1,000억 원에 적용하면 연 약 5.3억 원의 추가 이자입니다 → 만기 분산, 선제 조달, 약정 유동성 한도 확보가 필요합니다. |
| 채권 투자·WM | 금리만 보면 2022년 10~12월은 안정기로 보이지만 스프레드는 47bp 커졌습니다. 금리와 스프레드를 함께 봐야 하며, 계기판이 경색일 때는 발행사 등급부터 확인한 뒤 우량채를 검토 대상에 올릴 수 있습니다(위기 한 번의 사후 관찰). |
| 단기자금 관리 | CP − CD는 AA−보다 약 4개월 늦게 복귀했습니다. CP·전자단기사채로 차환하는 기업은 채권시장이 풀린 뒤에도 단기 조달 비용이 오래 남는 것에 대비해야 합니다. |
| 정책·시장 해석 | 50조원+α 대책 직후 5영업일에도 CP − CD는 +34bp 더 벌어졌습니다(같은 시기 기준금리 인상이 겹쳐 대책 효과는 따로 떼어 보지 않음). 2023년 하반기 스프레드는 평소의 1.7배라 '평소 수준'을 다시 잡아야 합니다. |

자세한 근거는 `output/REPORT.html` 9장에 있습니다.

> **'사건 전'은 평상시가 아닙니다.** 2022년 7~9월 스프레드(월평균 89~100bp)는 2019–21년 기준으로 이미 긴장 구간(9월은 경색)이었습니다. 그래서 '사건 전 대비'는 사건 직전과의 비교이고, 평상시와의 비교는 2019–21년 평균(45.9bp)을 기준으로 따로 했습니다. 일별 분석의 '사건 직전 범위'(2022.07.01–09.27 평균 + 2σ)도 계기판의 '평온'(2019–21년 기준)과 계산 규칙만 같고 기준 기간이 다릅니다.

## 5. 데이터 출처와 수집 방법

### 데이터 출처

| 출처 | 수집 방식 | 내용 | 주기·기간 |
|---|---|---|---|
| [e-나라지표 시장금리 추이](https://www.index.go.kr/unity/potal/main/EachDtlPageDetail.do?idx_cd=1073) | `requests` + `BeautifulSoup` 크롤링 | 국고채 3년, 회사채 3년(AA−), CD 91일 | 월별(월평균), 2019.01–2023.12 |
| [한국은행 ECOS Open API](https://ecos.bok.or.kr/api/) | `requests` → JSON | 국고채 3년, 회사채 3년(AA−·BBB−), CD 91일, CP 91일, 기준금리 | 일별, 2022.01–2023.06 (370영업일) |

**e-나라지표 월별 값은 월평균입니다.** ECOS 일별 값으로 같은 18개월을 계산하면 월평균과의 차이는 최대 0.01%p(반올림 수준), 월말값과의 차이는 최대 0.44%p입니다(`check_monthly_basis()`). 그래서 날짜 단위 판단(이탈일·급변일·복귀일)은 일별 ECOS 자료로 했습니다.

### 크롤링 방법

실제 수치는 HTML table이 아니라 `div.conBody span.img_box`(지표해석) 안의 텍스트에 있습니다. BeautifulSoup의 `select`로 이 요소를 찾고, 국고채·회사채·CD 제목을 모두 가진 요소가 정확히 1개인지 확인한 뒤 정규식으로 `('22.10월) 4.24` 같은 토큰을 추출합니다(`extract()`). 구조 분석 기록은 `output/page_structure.json`에 있습니다.

### 수집 허용 확인과 요청 원칙

- **robots.txt:** `check_robots()`가 `https://www.index.go.kr/robots.txt`를 받아 대상 페이지의 허용 여부를 판정하고 `data/raw/robots_check.json`에 남깁니다. 차단이면 수집을 멈춥니다. 온라인 수집 때는 자동으로 먼저 실행되고, 저장 원본을 그대로 둔 채 판정만 다시 하려면 `--check-robots`를 붙입니다.
- **확인 시점:** 제출된 원본은 2026-09-23에 수집했고, robots.txt 확인은 그 뒤인 2026-09-27에 별도로 했습니다. e-나라지표는 robots.txt가 없어(HTTP 404) '판단 보류'로 기록되어 있습니다. 이 기록은 분석 환경의 네트워크 제한 때문에 `check_robots()` 대신 외부 웹 조회로 확인한 것이며, 인터넷이 되는 PC에서 `--offline --check-robots`를 실행하면 코드 판정 결과로 덮어씁니다.
- **해석:** robots.txt가 없다는 것은 금지 표시가 없다는 뜻일 뿐 허용을 뜻하지 않으므로 아래 요청 원칙을 지켰습니다. 저장 원본 HTML에서 공공누리·저작권·이용약관 표시 문구를 코드로 검색했지만 찾지 못해, 출처를 표시하고 비상업 교육 목적으로만 사용합니다.
- **요청 방식:** 대상 페이지는 1회만 요청하고 User-Agent에 교육용 단일 요청임을 밝혔습니다. 이후 분석은 `--offline`으로 저장 원본을 재사용해 반복 요청하지 않습니다. timeout, `raise_for_status()`, Content-Type 검사를 적용했습니다.
- **ECOS:** 인증키로 호출하는 공식 Open API이며 지표 6개를 0.5초 간격으로 한 번씩 요청합니다. **API 키는 코드·파일·오류 메시지 어디에도 저장하지 않습니다.**

## 6. 전처리

원칙은 **고치지 않고, 확인하고, 문제가 있으면 멈춘다**입니다.

1. 2자리 연도를 20YY로 바꾸고 월을 날짜형(월초)으로 변환합니다. 원자료의 `raw_date`는 두 자리 월('19.01')로 저장해 CSV를 다시 읽어도 1월과 10월이 섞이지 않습니다.
2. 수익률을 숫자로 바꾸고 날짜·지표 중복을 검사합니다. 변환 실패·중복·결측·누락 월(수집 전체 60개월과 분석 18개월 모두)이 있으면 임의 값을 넣지 않고 멈춥니다. **결과: 중복 0건, 결측 0건, 누락 월 0건.**
3. 세 시계열을 월별로 결합(pivot)하고 스프레드(bp)와 전월 대비 변화를 계산합니다.
4. 보간·이상값 제거는 하지 않았습니다. 위기의 급등 자체가 분석 대상이기 때문입니다.
5. ECOS 일별 자료는 기준금리만 다음 변경 전까지 같은 값을 이어 붙이고 시장금리는 대체하지 않습니다.
6. ECOS 일별 값으로 월별 값이 월평균인지 판별합니다(`check_monthly_basis()`).

## 10. 한계와 주의점

- **인과관계가 아닙니다.** 같은 시기에 기준금리 인상(10/12, 11/24), 흥국생명 콜옵션 미행사(11/1), 글로벌 긴축이 겹쳐 레고랜드만의 효과를 분리하지 않았습니다.
- **CD·CP − 기준금리는 금리 인상 기대도 담고 있습니다.** 신용 불안만 보려면 CP − CD를 보세요.
- **BBB− 금리는 등급 간 전이 분석에 쓰지 않았습니다.** AA−와의 차이가 2022년 내내 약 585bp로 거의 고정되었다가 2023년 2분기 약 639bp로 계단식으로 올랐습니다. 거래가 드문 비우량 채권의 평가 방식 때문으로 보입니다.
- **계기판은 한 번의 큰 위기만 포함한 5년 자료로 만든 판정 틀입니다.** bp 스프레드는 금리 수준이 높을수록 커지는 경향이 있어, 금리 환경이 크게 바뀌면 기준값을 다시 계산해야 합니다.
- **6개월 초과수익은 근사치입니다.** 월평균 지수로 계산했고 롤다운·부도손실·거래비용을 넣지 않았습니다. 경색 매수 5회는 한 위기 안의 겹치는 기간이므로 매수 신호로 단정하지 않습니다.
